# 💎 OSINT — بوت تيليجرام الشامل (مصادر علنية فقط)

بوت تيليجرام عربي تفاعلي لجمع المعلومات من **المصادر المفتوحة (OSINT)** وبحث **Google Dorks** بضغطة زر — و**كل النتائج تظهر داخل تيليجرام** بدون فتح المتصفح.

> ✅ لا يحتاج أي مفتاح API مدفوع. مفتاح مجاني واحد اختياري (Serper) يفعّل نتائج Google داخل المحادثة.

---

## ✨ المميزات

| القسم | ماذا يعرض داخل تيليجرام؟ |
|---|---|
| 📥 **تحميل مقاطع وصور** | فقط أرسل الرابط (بدون قائمة): يصلك **المقطع** بصيغة H.264 وصوت AAC 192k موحّد المستوى، أو **الصور** كألبوم (بما فيها منشورات الصور في TikTok مع موسيقاها) — مع كل المعلومات: تاريخ ووقت النشر، المشاهدات، الإعجابات، التعليقات، المشاركات، الحفظ، الصوت. تحت كل مقطع زر **🎵 تحميل الصوت MP3** |
| 📊 **معلومات حساب** | أرسل يوزر أو رابط حساب: الاسم، النبذة، المتابِعون، المتابَعون، المنشورات، الإعجابات، التوثيق، تاريخ الإنشاء على TikTok و Instagram و X + **صورة الحساب** و**آخر فيديوهات TikTok** مع زر تحميل لكل فيديو + سؤال **📖 تحميل ستوريات Instagram** (يتطلب `INSTAGRAM_SESSIONID`) |
| 🔎 **Google Dorks** | أرسل اسماً أو كلمة أو دوميناً واختر من **قائمة خيارات جاهزة** (ملفات PDF/Excel/Word، مواقع حكومية وأكاديمية، شبكات اجتماعية، LinkedIn، أخبار، منتديات، GitHub، Pastebin، صفحات الدخول، النطاقات الفرعية...) — أو أرسل Dork جاهز وينفّذ فوراً. النتائج كصفحات داخل المحادثة مع زر 📥 للملفات |
| 🕵️ **البحث المتقدم** | يتفرّع إلى **🎵 TikTok / 📸 Instagram / 𝕏 تويتر** — لكل منصة Google Dorks خاصة بها (الحساب، الفيديوهات/المنشورات/التغريدات، الهاشتاقات، الأصوات، الأماكن، الإشارات، آخر سنة...) والنتائج داخل المحادثة مباشرة |
| 🌐 **دومين** | DNS، بيانات التسجيل (RDAP / WHOIS)، الاستضافة، المنافذ المفتوحة، أول وآخر أرشفة + أزرار: النطاقات الفرعية، فحوصات urlscan مع **لقطة شاشة للموقع**، تقرير IP الخادم، الملفات المنشورة، صفحات الدخول... |
| 🌐 **IP** | الموقع التقريبي، المزود، ASN، Reverse DNS، **المنافذ والثغرات المعروفة (Shodan InternetDB)**، السمعة (GreyNoise)، جهة الإبلاغ + **دبوس الموقع على خريطة تيليجرام** |
| 📞 **هاتف** | الدولة، نوع الرقم، المشغّل الأصلي، المنطقة الزمنية + نتائج البحث عن الرقم داخل المحادثة + فتح المحادثة في واتساب/تيليجرام |
| 👤 **يوزر** | فحص فوري على 10 منصات + ملف GitHub العلني + **فحص شامل في +600 موقع (WhatsMyName) مع شريط تقدم** + نتائج البحث في X و Instagram و TikTok و Facebook وغيرها |
| 🔗 **رابط/ملف (Docs)** | نتائج PDF / Word / Excel / PowerPoint والمواقع الحكومية والأبحاث — و**زر 📥 يرسل الملف نفسه داخل المحادثة** |
| ✉️ **إيميل** | نوع المزود، MX، SPF و DMARC، **قائمة التسريبات التي ظهر فيها البريد (XposedOrNot)**، ملف Gravatar العلني + **صورته داخل المحادثة** |

> ℹ️ **عن البحث داخل تيليجرام:** محركات البحث تحجب البحث المجاني القادم من الخوادم، لذلك أزرار نتائج Google
> تحتاج مفتاحاً مجانياً من [serper.dev](https://serper.dev) (2,500 بحث مجاني بدون بطاقة بنكية). بقية الميزات تعمل بدون أي مفتاح.

**مميزات تقنية:**
- ⚡ مبني على `python-telegram-bot` الإصدار 22 (غير متزامن async) مع `ConversationHandler`.
- 👥 يخدم عدة مستخدمين في نفس الوقت (`concurrent_updates`).
- 🛡️ معالجة كاملة للأخطاء: المدخلات الخاطئة أو بطء المصادر لا توقف البوت أبداً.
- ⏳ حماية من الإغراق (فترة انتظار بين عمليات البحث).
- 💾 حفظ تلقائي للمستخدمين والإحصائيات وحالة المحادثات (`PicklePersistence`).
- 🔢 يدعم الأرقام العربية (١٢٣) والنطاقات العربية تلقائياً.
- 👑 أوامر خاصة بالمالك: `/stats` و `/broadcast`.

## 🚀 التثبيت والتشغيل

### 1️⃣ المتطلبات
- Python **3.10** أو أحدث.

### 2️⃣ تحميل المشروع وتثبيت المكتبات

```bash
git clone https://github.com/AQ2K/ticket-bot.git OSINT
cd OSINT
python -m venv venv
source venv/bin/activate        # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

### 3️⃣ إعداد التوكن 🔑

انسخ ملف القالب ثم ضع توكن البوت بداخله:

```bash
cp .env.example .env            # على ويندوز: copy .env.example .env
```

ثم عدّل ملف `.env`:

```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

> ⚠️ **مهم:** ملف `.env` مستثنى من git ولن يُرفع إلى GitHub — لا تكتب التوكن داخل `config.py` لأن المستودع عام.
> معرّف المالك `8876599674` مضبوط مسبقاً في `config.py`.

### 4️⃣ التشغيل

```bash
python main.py
```

افتح البوت في تيليجرام وأرسل `/start` 🎉

## 📱 التشغيل من GitHub مباشرة (بدون كمبيوتر — مناسب للآيفون)

البوت يعمل على خوادم GitHub عبر **GitHub Actions** (الملف `.github/workflows/bot.yml`)، ويمكن إعداده بالكامل من متصفح Safari:

1. **أضف التوكن كسرّ (Secret):**
   افتح [Settings ← Secrets and variables ← Actions ← New repository secret](https://github.com/AQ2K/ticket-bot/settings/secrets/actions/new)
   - **Name:** `BOT_TOKEN`
   - **Secret:** توكن البوت من ‎@BotFather‎
   ثم اضغط **Add secret**. (السرّ مشفّر ولا يظهر لأحد، حتى في السجلات)
2. **فعّل GitHub Actions:** افتح تبويب [Actions](https://github.com/AQ2K/ticket-bot/actions) واضغط الزر الأخضر
   **«I understand my workflows, go ahead and enable them»** (مطلوب لأن المستودع منسوخ Fork).
3. **شغّل البوت:** يبدأ تلقائياً عند أي تحديث على فرع `main`، أو يدوياً من
   Actions ← **🤖 تشغيل بوت OSINT** ← **Run workflow**.
4. **(اختياري) فعّل نتائج Google داخل تيليجرام:**
   - سجّل مجاناً في [serper.dev](https://serper.dev) وانسخ **API Key** من لوحة التحكم.
   - أضفه كسرّ جديد من [نفس صفحة الأسرار](https://github.com/AQ2K/ticket-bot/settings/secrets/actions/new) باسم `SERPER_API_KEY`.
   - أعد تشغيل البوت من Actions ← **🤖 تشغيل بوت OSINT** ← **Run workflow**.
5. **(اختياري) فعّل تحميل ستوريات Instagram:** Instagram لا يعرض الستوريات بدون تسجيل دخول.
   - من كمبيوتر: سجّل الدخول في instagram.com بحساب **ثانوي** ← أدوات المطوّر (F12) ← Application ← Cookies ← انسخ `sessionid`.
   - أضفه كسرّ باسم `INSTAGRAM_SESSIONID` ثم **Run workflow**. (ستوريات TikTok غير متاحة للزوار من خارج التطبيق)

**كيف يعمل؟**
- GitHub يوقف أي تشغيل بعد 6 ساعات، لذلك يعمل البوت 5 ساعات و45 دقيقة ثم يتوقف بأمان،
  ويكون تشغيل جديد في الانتظار ليستلم فوراً (فجوة أقل من دقيقة، والرسائل خلالها لا تضيع).
- المستخدمون والإحصائيات تُحفظ بين التشغيلات تلقائياً (GitHub Actions Cache).
- أي تحديث على `main` أو ضغط **Run workflow** يوقف النسخة الحالية ويشغّل الكود الجديد فوراً.

> ⚠️ **ملاحظات:**
> - GitHub يوقف الجدولة تلقائياً إذا لم يحدث أي نشاط في المستودع لمدة 60 يوماً — أعد تفعيلها من تبويب Actions.
> - شروط GitHub تنص على أن Actions مخصصة لتطوير البرمجيات وليست استضافة دائمة، لذا قد تُوقَف.
>   للاستضافة الدائمة الموثوقة استخدم سيرفراً (VPS) أو خدمة استضافة.
> - سجلات Actions علنية في المستودعات العامة (التوكن يُخفى تلقائياً).

## 🖥️ التشغيل الدائم على سيرفر (Linux + systemd)

أنشئ الملف `/etc/systemd/system/osint-bot.service`:

```ini
[Unit]
Description=OSINT Telegram Bot
After=network-online.target

[Service]
WorkingDirectory=/opt/OSINT
ExecStart=/opt/OSINT/venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

ثم:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now osint-bot
sudo journalctl -u osint-bot -f     # متابعة السجلات
```

> ℹ️ **عن Instagram:** يحجب Instagram كثيراً الطلبات المجهولة القادمة من الخوادم، لذلك قد يفشل أحياناً تحميل بعض المقاطع،
> وتُجلب معلومات الحساب من نتائج Google عند تفعيل مفتاح Serper. TikTok و X يعملان بدون أي مفتاح.

> ℹ️ المصادر المجانية لها حدود استخدام (مثل ip-api.com: 45 طلباً في الدقيقة، GitHub: 60 طلباً في الساعة، Serper: 2,500 بحث) — عند تجاوزها يعرض البوت «تعذّر التحقق» بدل التوقف.
